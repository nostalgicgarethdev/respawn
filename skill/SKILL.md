# Respawn

Paste a public link. The remake stays on the page.

## Read

1. Take the public https page, or the public Solana account.
2. Keep the title, text, headings, scripts, and forms. Keep a speed rule only when the page prints `SPEED`, `ACCELERATION`, and `MAX_SPEED`. Keep a pump.fun curve only from the bonding-curve account.
3. Put the source beside each line. Leave unread behavior unread.

## Build

- The remake is on the page.
- A printed speed rule plays. An open bonding curve trades in the browser. Any other page is the title, headings, scripts, and forms.

## Leave out

- Cheats, key extraction, anti-cheat bypass, and exploit steps.
- Any line that calls a browser trade a confirmed chain transaction.
