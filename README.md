# Respawn

Paste a public link. The remake stays on this page.

https://respawn-blush-five.vercel.app

A page is rebuilt from its title, headings, scripts, and forms. A page that prints a speed rule can be played. A pump.fun coin page trades the bonding curve in the browser. A Solana address shows the public account fields.

```bash
npm install
npm test
npm run dev
```
